# Security Policy

Report vulnerabilities privately through the repository's GitHub Security Advisories when enabled, or contact the repository maintainers through your established private channel. Avoid posting credentials, exploit details, or user data in public issues.

The Rust runtime requires TLS at its ingress, protected service networks, provider credentials scoped to its resources, and current security updates. Development Compose credentials are examples only. See [rewrite status](docs/REWRITE_STATUS.md) for unimplemented capabilities and validation boundaries.
